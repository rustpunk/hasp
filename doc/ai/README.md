# AI Onboarding Documentation

This directory is the durable onboarding set for future AI coding agents and human contributors working in this repository.

The docs are evidence-backed. Claims are tied to source files, tests, manifests, CI, existing documentation, or read-only subsystem discovery. When the evidence conflicts or is incomplete, the docs mark that explicitly instead of inventing intent.

Start with [00_READ_THIS_FIRST.md](00_READ_THIS_FIRST.md). Use [10_ARCHITECTURE.md](10_ARCHITECTURE.md) for system shape, [20_PROJECT_MAP.md](20_PROJECT_MAP.md) for path-level orientation, [30_DESIGN_RULES.md](30_DESIGN_RULES.md) for invariants, and [50_TESTING_AND_COMMANDS.md](50_TESTING_AND_COMMANDS.md) before claiming verification.

Update this directory when architecture, package layout, backend behavior, command policy, or contributor workflow changes. Keep source-of-truth user documentation in `docs/src/` and crate READMEs synchronized separately.
